# Hudson U2 — Compose / Send / AI wired into the app

> Built by a Workflow: each task implement (TDD) → adversarial review → fix, sequentially in the `u2-compose` worktree.

**Goal:** Make the SwiftUI app self-contained — compose + reply + send, a "Sync now" button, and the Summarize chip actually work in the window (no dropping to the CLI). This is the "use it myself" milestone.

**Architecture:** Thin UI-side seams over the merged M5/M7 engines. `SendBootstrap` builds a `SendService` from Keychain creds (mirrors the existing `SyncBootstrap`); `ComposerModel`/`ComposerView` drive compose+reply+undo; `AIBootstrap` builds an `EgressGuard`+`Summarize` from `ai_config`+Keychain and streams a summary into the existing AI chip. Everything reuses public APIs already on `main`. Sources of truth: the M5 plan (Outbox), M7 plan (AIKit), and spec §7/§8.

**Tech Stack:** Swift 6, SwiftUI, GRDB (via Store). No new external deps. Design tokens ONLY (Palette/Typography/Metrics). House readability bar.

## Global Constraints
- **Privacy #1:** send + summarize are USER-INITIATED only. AI egress goes through `EgressGuard` (opt-in gated) exactly as M7 requires — the chip tap is the explicit `Invocation.userInvoked(.summarize)`. No auto-send, no auto-summarize (no summarize-on-open/scroll), no telemetry.
- **Swift 6 strict concurrency**; view models `@MainActor @Observable`. Two external deps only. Match the existing HudsonUI model/view patterns (`AppModel`, `SearchModel`, `ThreadView`).
- **Send correctness:** always go through `SendService.enqueue` → `flushOnce` (the dedup state machine); the undo window is `SendService.cancel(jobID:now:)` during the hold. `now = Int64(Date().timeIntervalSince1970 * 1000)`.

## Interfaces on `main` you build on (READ these files)
- `Sources/HudsonUI/Model/SyncBootstrap.swift` — `SyncBootstrap.makeStack(database:account:) -> SyncStack?` (the Keychain→GmailClient seam to mirror). `GmailClient` already conforms to `SendTransport` (`Sources/Outbox/SendService.swift:17`).
- `Sources/Outbox/SendService.swift` — `SendService(api: any SendTransport, database, account)`, `enqueue(_ OutboxMessage, undoHold: Duration = .seconds(15), now:) -> Int64`, `cancel(jobID:now:) -> Bool`, `flushOnce(now:) -> Int`.
- `Sources/Outbox/OutboxMessage.swift` — `OutboxMessage(from:to:cc:bcc:subject:bodyText:bodyHTML:attachments:inReplyTo:references:threadID:)`. `Sources/Outbox/ReplyBuilder.swift` — `replyMessage(to threadID:account:database:from:bodyText:bodyHTML:replyAll:) async throws -> OutboxMessage`.
- `Sources/AIKit/EgressGuard.swift` — `EgressGuard(provider: any LLMProvider, database, account)`, `run(_ request, for: Invocation)`. `Sources/AIKit/Summarize.swift` — `Summarize(guard:database:account:)`, `summarize(threadID:invocation:) -> AsyncThrowingStream<String,Error>`. `Sources/AIKit/{AnthropicProvider,OpenAICompatProvider}.swift`, `Invocation.userInvoked(.summarize)`. `ai_config` via `HudsonDatabase.aiConfig(feature:account:)`; keys via `KeychainLLMKeyStore` (service "com.hudson.llm").

## Task 2: ComposerModel (compose/reply/send/undo) — CRUX
**Files:** `Sources/HudsonUI/Model/ComposerModel.swift`; test `Tests/HudsonUITests/ComposerModelTests.swift`.
**Produces:** `@MainActor @Observable final class ComposerModel` with:
- `init(database:account:makeService: @escaping () -> SendService? = { ... default via SendBootstrap ... })` (the injectable factory lets tests pass a `SendService` built over a fake `SendTransport`).
- Fields: `var to, cc, subject, bodyText: String`; `enum Mode { case new; case reply(threadID: String) }`; `private(set) var mode`.
- `func startNew()` / `func startReply(threadID:) async` — the reply path prefills `to`/`subject`/`bodyText`(quoted) + carries `inReplyTo`/`references`/`threadID` by building via `ReplyBuilder.replyMessage(...)` (store the derived `OutboxMessage` scaffold; the user edits the body).
- `func send() async` — build the `OutboxMessage` (new: from fields; reply: the scaffold with the edited body), `makeService()` (nil → set a "connect an account" banner, return), `enqueue(...)` (store `undoJobID`), then `flushOnce(now:)` in a `Task`. Set `justSentUndoJobID` for the undo window; clear fields; close on success.
- `func undo() async` — `service.cancel(jobID:now:)` within the hold; report cancelled/too-late.
- `isSending`, `banner: String?`.
**Steps:** failing tests (send enqueues a job via an injected fake SendService and reports an undo id; undo within hold cancels; reply mode prefills subject via `SubjectNormalization`/ReplyBuilder) → implement → commit `feat(ui): ComposerModel — compose, reply, send, undo`.

## Task 5: AIBootstrap + Summarize chip — CRUX (privacy)
**Files:** `Sources/HudsonUI/Model/AIBootstrap.swift`, `Sources/HudsonUI/Model/SummaryModel.swift`; modify `ThreadView.swift`; tests.
**Produces:**
- `enum AIBootstrap { static func makeSummarize(database:account:) async -> Summarize? }` — read `aiConfig(feature: .summarize, account:)`; if `optIn != true` return nil (fail-closed, matches EgressGuard). Build the provider: `.anthropic` → `AnthropicProvider(http: URLSessionLLMHTTP(), apiKey: KeychainLLMKeyStore key)`, else `OpenAICompatProvider(...)` with the configured base URL; wrap in `EgressGuard(provider:database:account:)` → `Summarize(guard:...)`.
- `@MainActor @Observable final class SummaryModel { func summarize(threadID:) async }` — mints `Invocation.userInvoked(.summarize)` (the chip tap IS the explicit action), streams deltas into `private(set) var text` + `isStreaming`; if `AIBootstrap.makeSummarize` returns nil, set `needsSetup = true` (banner: "Enable AI: `hudson ai config --feature summarize --opt-in …`").
- `ThreadView`: the existing amber "✦ Summarize thread" chip → `onSummarize` → runs `SummaryModel.summarize`; render the streamed summary in the `aiBg`/`aiInk` area; the not-opted-in state shows the setup banner. **No auto-run** — only on explicit tap.
**Steps:** failing tests with a fake provider via an injected guard: opted-in streams a summary into `text`; not-opted-in sets `needsSetup` and never egresses (assert zero provider calls) → implement → commit `feat(ui): AIBootstrap + Summarize chip (explicit, opt-in gated)`.
