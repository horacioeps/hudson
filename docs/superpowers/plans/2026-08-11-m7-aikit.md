# Hudson M7 — AIKit Implementation Plan

> Built by a Workflow: each task implement → adversarial review (correctness + test-rigor, plus a PRIVACY/EGRESS lens on the crux tasks) → fix. Sequential in the `m7-ai` worktree.

**Goal:** A quiet, explicit-invocation-only AI layer — summarize, draft-in-voice, ask-inbox — with a **type-level no-background-egress guarantee**, streaming providers, and content-addressed caching. Privacy is the #1 product rule: mail content leaves the machine ONLY to the user's configured provider, ONLY on explicit invocation, NEVER in the background, NO telemetry.

**Architecture:** New `AIKit` library target composing **only `Store` + its own streaming LLM providers — never `GmailKit`** (mirrors how Runtime wires SyncEngine over the DB). Sources of truth (implementers + reviewers MUST read both): spec `docs/superpowers/specs/2026-08-10-hudson-foundation-design.md` §8 (AIKit + the egress table + privacy stance), and `docs/superpowers/design/2026-08-10-speed-ai-architecture.md` the **"M7 — AIKit"** section (the four pillars, model choices, the 5-series request contract, ask-inbox two-hop).

**Tech Stack:** Swift 6 strict concurrency, GRDB (via Store), `URLSession` streaming (`.bytes`). Swift Testing. **No new external deps** (URLSession/Foundation are OS APIs).

## Global Constraints

- **Privacy #1 — the load-bearing invariant.** `EgressGuard` is the SINGLE internal choke point and the ONLY code that ever calls `provider.stream`. It is reachable only via an `Invocation` token that can be minted ONLY from an explicit CLI/UI action AND a per-feature opt-in row (`ai_config.opt_in`). No ambient/default `Invocation` constructor exists (private init + explicit factory), so no background code path can egress — a compile-time guarantee, not a convention. No auto-summarize-on-scroll, no background refresh, no telemetry, ever. Every reviewer verifies there is no `provider.stream` call outside `EgressGuard`, and no `Invocation`/permit constructible without an explicit-action factory.
- **Streaming is mandatory** (5-series contract + avoids HTTP timeouts). `LLMHTTP` is a genuine streaming byte seam (`URLSession.bytes → AsyncThrowingStream<UInt8>`), NOT the buffered `HTTPTransport`.
- **5-series request contract:** NO `temperature`/`top_p`/`top_k` (they 400 on 5-series), NO `budget_tokens`; adaptive thinking; handle `stop_reason == "refusal"` gracefully (branch BEFORE reading content).
- **Models are config-driven via `ai_config`, never hardcoded:** Summarize default `claude-haiku-4-5`; Draft/Ask/voice-profile default `claude-sonnet-5`. Read the model from `ai_config`, fall back to these defaults.
- **NO new migrations in M7.** Reuse the existing `ai_artifacts` / `ai_config` / `ai_artifact_sources` tables (M4). Voice profile is an `ai_artifacts` row (`kind: "voice_profile"`, `sources: []`). **Migration `v7` is RESERVED for the concurrently-built M5 branch — do not add any migration here.**
- **Two external deps only** (swift-argument-parser, GRDB). Keys from Keychain via the existing `LLMKeyStore`/`KeychainLLMKeyStore` (GmailKit); tests use `InMemoryLLMKeyStore`.
- **AIKit owns its own 429 backoff** (QuotaBucket is Gmail-only).
- **Readability bar (open-source):** WHY-comments, full-word names, focused files.

## Task 1: AIKit target + LLMProvider protocol + Invocation + EgressGuard (PRIVACY CRUX)

**Read first:** architecture "M7 — AIKit" pillars 1 & 2; spec §8 egress table + privacy stance.

**Interfaces (Produces):**
- `public enum AIFeature: String, Sendable { case summarize, draft, ask, voiceProfile }`
- `public struct LLMMessage: Sendable { public enum Role: String, Sendable { case system, user, assistant }; public let role: Role; public let text: String }`
- `public struct LLMRequest: Sendable { public let model: String; public let system: String?; public let messages: [LLMMessage]; public let maxTokens: Int }`
- `public enum LLMEvent: Sendable { case textDelta(String); case thinkingDelta(String); case usage(inputTokens: Int, outputTokens: Int); case refusal; case stopped }`
- `public protocol LLMProvider: Sendable { func stream(_ request: LLMRequest) -> AsyncThrowingStream<LLMEvent, Error> }`
- `public struct Invocation: Sendable` — represents ONE explicit user invocation of a feature. `private init`; the ONLY public way to obtain one is `public static func userInvoked(_ feature: AIFeature) -> Invocation`. (Naming it `userInvoked` makes every call site read as an explicit user action; background code cannot fabricate one accidentally.)
- `public actor EgressGuard` with `init(provider:database:account:)`. Its ONLY method that egresses: `func run(_ request: LLMRequest, for invocation: Invocation) async throws -> AsyncThrowingStream<LLMEvent, Error>` — checks `database.aiConfig(feature:account:)?.optIn == true` (else throws `AIError.notOptedIn(feature)`), then calls `provider.stream`. **`provider.stream` must be called from NOWHERE else in the codebase.** Feature modules (T5–T7) obtain their stream ONLY via `EgressGuard.run(_, for:)`, passing an `Invocation` their public API received from the caller.

- [ ] TDD: (a) `EgressGuard.run` throws `notOptedIn` when the feature's `ai_config.opt_in` is false/absent; (b) with opt-in, it forwards to the provider (use a mock `LLMProvider` returning scripted events); (c) an `Invocation` cannot be constructed except via `userInvoked` (compile-time — assert by construction in code + a comment; add a doc test). Commit `feat(aikit): LLMProvider + Invocation token + EgressGuard egress choke point`.

## Task 3: AnthropicProvider (event-typed SSE, 5-series contract) (EGRESS CRUX)

**Read first:** architecture "5-series request contract (verified)".

**Interfaces:** `public struct AnthropicProvider: LLMProvider` `init(http: LLMHTTP, apiKey: String, baseURL: URL = api.anthropic.com)`. Builds the Messages API request: `model`, `system`, `messages`, `max_tokens`, `stream: true`, `anthropic-version` header, `x-api-key`. **Omit `temperature`/`top_p`/`top_k`/`budget_tokens` entirely** (they 400 on 5-series). Parses event-typed SSE (`content_block_delta` → `.textDelta`; `thinking` deltas → `.thinkingDelta`; `message_delta`/`message_stop` → `.usage`/`.stopped`; `stop_reason == "refusal"` → `.refusal` BEFORE any content). Own 429 backoff.

- [ ] TDD with `ScriptedLLMHTTP` fixtures: a normal streamed answer yields ordered `.textDelta`s then `.usage`+`.stopped`; a refusal fixture yields `.refusal` and no content; a 429 fixture retries with backoff; assert the request body omits the forbidden fields. Commit `feat(aikit): AnthropicProvider (event SSE, 5-series contract, refusal + 429)`.

## Task 4: OpenAICompatProvider (data-chunk SSE, base-URL configurable) (EGRESS CRUX)

## Task 5: Summarize (thread → cached Haiku summary)

**Read first:** architecture Summarize (Haiku 4.5, keyed `(thread_id, last_message_id)`), egress table row ("the one thread").

**Interfaces:** `public struct Summarize { init(guard: EgressGuard, database:account:) ; func summarize(threadID: String, invocation: Invocation) async throws -> AsyncThrowingStream<String, Error> }` — cache check first (`artifact(kind:"summary", key: threadID+lastMessageID, model, promptVersion)`); on hit, yield the cached text (zero egress). On miss: build the context from `threadMessages` + bodies (plain text only — NEVER raw HTML), model from `aiConfig(feature:.summarize)` ?? `claude-haiku-4-5`, `EgressGuard.run(request, for: invocation)`, stream deltas to the caller AND accumulate → `putArtifact(...)` with `sources = the thread's message ids` (so a message deletion purges it). The stream the caller sees is the live deltas; the cache write happens as they land.

- [ ] TDD: cache hit yields cached text with NO provider call (mock provider asserts zero calls); cache miss calls the provider (scripted) and writes an artifact whose sources are the thread messages; not-opted-in throws. Commit `feat(aikit): summarize (cached, thread-only egress)`.

## Task 6: Voice profile + Draft-in-voice

**Read first:** spec §8 Draft (voice profile, explicit-invocation-only refresh), egress table ("voice profile + current thread + instruction").

**Interfaces:**
- `public struct VoiceProfile { func current(invocation: Invocation, forceRefresh: Bool) async throws -> String }` — reads the cached profile (`ai_artifacts kind:"voice_profile", key: account`); if absent OR `forceRefresh`, distill from `sentMessages(account:limit:)` via Sonnet (explicit invocation), cache it. Refresh happens ONLY here (first use, staleness during an explicit draft, or the explicit refresh command) — NEVER in the background.
- `public struct Draft { func draft(replyTo threadID: String?, instruction: String, invocation: Invocation) async throws -> AsyncThrowingStream<String, Error> }` — context = voice profile + (thread if reply) + instruction, model `aiConfig(feature:.draft) ?? claude-sonnet-5`, via `EgressGuard.run`.

- [ ] TDD: voice profile distilled once then cached (second call no provider hit unless forceRefresh); draft builds the voice+thread+instruction context and streams; not-opted-in throws. Commit `feat(aikit): voice profile + draft-in-voice`.

## Task 7: AskInbox (retrieve → cited answer)

**Read first:** architecture ask-inbox two-hop; spec §8 AskInbox (FTS5 + recency/sender heuristics, message-id citations, hydration coverage surfaced).

**Interfaces:** `public struct AskInbox { func ask(_ question: String, invocation: Invocation) async throws -> AsyncThrowingStream<AskEvent, Error> }` where `AskEvent` carries `.textDelta(String)` and a final `.citations([messageID])` + `.coverage(hydratedFraction: Double)`. Retrieve top-k via `searchMessages` (+ recency/sender heuristics); optional Haiku query-expansion hop for non-lexical questions (skip for lexical); Sonnet answer with message-id citations, streamed. Egress = question + top-k retrieved messages only.

- [ ] TDD: retrieval selects the seeded relevant messages; the answer stream includes citations to their ids; lexical query skips expansion; not-opted-in throws. Commit `feat(aikit): ask-inbox (retrieval + cited streamed answer)`.

## Task 8: CLI — summarize / draft / ask / ai config

**Interfaces:** `hudson summarize <threadID>`, `hudson draft [--reply <threadID>] --instruction <s>`, `hudson ask "<question>"`, and `hudson ai config --feature <f> --provider <anthropic|openai-compat> --model <m> --base-url <u> --opt-in` (writes `ai_config` + stores the key via `KeychainLLMKeyStore`). Each command mints `Invocation.userInvoked(...)` (this IS the explicit-action boundary), builds the provider from `ai_config`, streams to stdout (sanitized via `Sanitizer.terminalSafe`). `ai config` is the ONLY way opt-in is turned on.

- [ ] TDD where feasible (arg parsing; a dry-run against a scripted provider + temp DB). Commit `feat(cli): summarize / draft / ask / ai config`.
